DOV Uploader

DOV Uploader is a small private tool that publishes the videos of the "Demek O Yüzden" channel to that channel's own YouTube account.

What it does

  • Uploads a finished video file to the channel owner's YouTube channel.
  • Sets the title, description, category, visibility and thumbnail of that video.
  • Optionally schedules the video to go public at a chosen time.

Who uses it

Only the channel owner. It is not a public service, it has no sign-up, and it does not handle anyone else's account or data.

How it connects

The tool uses YouTube API Services. The channel owner authorizes it once through Google's own consent screen and can remove that access at any time from Google Account permissions.

Contact

Questions can be raised as an issue on the project repository.
